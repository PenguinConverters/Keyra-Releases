Linux (x64)

Debian / Ubuntu (.deb) Fedora / RHEL (.rpm) Portable archive (.tar.gz)

No runtime to install: every Linux build carries its own. It needs GTK 4 and git, which the .deb and .rpm request for you.
The packages install to /opt/keyra, add a menu entry, and read machine-wide policy from /etc/keyra/policy.json. The portable archive unpacks anywhere and needs no root, which is what the in-application updater uses.
